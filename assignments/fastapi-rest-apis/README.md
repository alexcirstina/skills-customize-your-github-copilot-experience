# 📘 Assignment: Building REST APIs with FastAPI

## 🎯 Objective

Learn how to build and test RESTful APIs using the FastAPI framework in Python. You will create endpoints, handle requests, and return JSON responses.

## 📝 Tasks

### 🛠️ Set Up FastAPI Project

#### Description
Initialize a FastAPI project and set up the basic structure for your API application.

#### Requirements
Completed program should:

- Include a `requirements.txt` file with FastAPI and Uvicorn
- Create a starter FastAPI app in `starter_app.py`
- Run the app locally using Uvicorn


### 🛠️ Implement API Endpoints

#### Description
Add RESTful endpoints to your FastAPI app for basic CRUD operations (Create, Read, Update, Delete) on a simple resource (e.g., items, users).

#### Requirements
Completed program should:

- Implement at least 4 endpoints: GET, POST, PUT, DELETE
- Handle JSON request and response bodies
- Return appropriate status codes and error messages
- Test endpoints using curl or a tool like Postman
